# Usage Widgets

Two native Windows desktop usage widgets in one repo. Each is a single .NET Framework 4.8 WPF executable.

| Widget | What it shows | Run |
| --- | --- | --- |
| [UsageWidget](UsageWidget/) | Codex quota | `UsageWidget/native/bin/UsageWidget.exe` |
| [GrokUsageWidget](GrokUsageWidget/) | Grok Build and Grok Bot, as two separate meters | `GrokUsageWidget/bin/GrokUsageWidget.exe` |

The executables in this repo are the copies from the Desktop. Source for each widget is in its own folder.
